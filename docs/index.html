Bantuan Akses & Kongsi Pautan

Buka Tab Baharu
  1. Jika pautan dibuka dari WhatsApp, gunakan menu pelayar untuk buka dalam Safari atau Chrome.
  2. Jika halaman Google gagal dibuka, cuba tetingkap Private/Incognito. Jika diminta log masuk, gunakan satu akaun Google sahaja.
  3. Kongsi pautan GitHub Pages aplikasi ini. Pautan /exec digunakan sebagai sambungan data sahaja.
  4. Jika masih gagal, minta pemilik menyemak deployment dan dasar akaun sekolah.

Butang tab baharu mungkin masih menggunakan pelayar dalam aplikasi. Pilih Safari/Chrome secara manual melalui menunya.
