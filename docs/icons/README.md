Original concept generated with the built-in image generation tool; resized and compressed for browser use.

Generation prompt: Create one polished app icon for eRekTas, a Malaysian primary-school Quran/Iqra reading progress record app for teachers. A simple open Quran/book with ivory pages, a gold bookmark and an emerald checkmark badge. Premium contemporary flat vector-like app mark, bold clean geometry, restrained depth and legible small sizes. Square, centered composition with essential artwork inside the central 62 percent for mobile masks. Full-bleed rich emerald background, no rounded outside corners, opaque. No writing, letters, mockups, watermarks or additional objects.
